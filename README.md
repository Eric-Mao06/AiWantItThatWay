# AI Assistant Desktop Widget

A sleek, modern desktop assistant built with Electron that provides context-aware suggestions and minimizes user input.

## Features

- **Proactive Suggestions**: The assistant provides context-aware suggestions that users can activate with a simple Tab key press.
- **Minimal UI**: Clean, modern interface with a focus on the assistant's suggestions rather than user input.
- **Visual Feedback**: Beautiful animations and transitions provide feedback when interacting with the assistant.
- **Dynamic Content**: The assistant's messages rotate to show different context-aware suggestions.

## Design Philosophy

This assistant is designed with the following principles in mind:

1. **Proactive over Reactive**: The assistant should anticipate user needs rather than waiting for explicit commands.
2. **Minimal Input**: Users should be able to accomplish tasks with minimal typing or clicking.
3. **Contextual Awareness**: The assistant should understand and adapt to the user's current context.
4. **Aesthetic Appeal**: The interface should be visually pleasing and non-intrusive.

## Technical Implementation

- Built using Electron for cross-platform desktop compatibility
- Modern CSS with gradients, animations, and responsive design
- JavaScript for dynamic content and user interactions

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

1. Clone the repository:
```
git clone https://github.com/armaangupta06/AIWantItThatWay.git
```

2. Navigate to the project directory:
```
cd AIWantItThatWay
```

3. Install dependencies:
```
npm install
```

4. Start the application:
```
npm start
```

## Usage

- Press **Tab** to activate the current suggestion
- Press **Space** to show/hide the input box for manual queries
- Press **Escape** to hide the input box
